# Установка в Битрикс24

«Отчёт по счетам» — это **локальное приложение** (тип 1) Битрикс24: упакованный ZIP-архив, который добавляется через интерфейс управления приложениями. Серверного бэкенда у приложения нет.

## Шаг 1. Собрать ZIP-артефакт

```bash
npm install   # один раз — ставит archiver
npm run pack  # → dist/fin25_otch.zip
```

Проверьте вывод: размер должен быть ≤ 500 KB. Sanity-check автоматически отклоняет архив, если в него попали файлы из blacklist (`.env`, `dev-config.local.js`, `tests/`, `*.md`, `package.json`, `node_modules` и т. д.).

## Шаг 2. Загрузить ZIP в Битрикс24

1. Откройте портал → раздел **Приложения**.
2. **Разработчикам → Другое → Локальное приложение** (или прямой URL: `<portal>/marketplace/local/`).
3. Заполните поля:
   - **Код приложения:** `fin25_otch` (любой уникальный).
   - **Название:** `Отчёт по счетам`.
   - **Тип размещения:** обычно «В разделе CRM» либо «Самостоятельное приложение».
   - **Доступные права:** `crm`, `user`. Этого хватает для `crm.item.list` (entityTypeId=31), `crm.contact.list`, `user.get`.
4. **Загрузить ZIP-архив** → выберите `dist/fin25_otch.zip`.
5. Сохраните.

## Шаг 3. Открыть приложение

Битрикс автоматически отдаст `index.html` из архива. На первой загрузке выполнится `BX24.init()`, затем `bootstrap()` подгрузит список ответственных и применит дефолтный фильтр (текущий месяц).

Если что-то не загружается:

- Откройте DevTools → консоль. На портале логирование молчит, чтобы не мешать; добавьте `?DEBUG=true` в URL приложения, чтобы включить verbose-логи.
- Проверьте, что у приложения есть права `crm` и `user`.
- Проверьте размер ZIP — если > 500 KB, Битрикс может отказать в загрузке.

## Ограничения локальных приложений

- **Без бэкенда.** Любое обращение к Битриксу — только через `BX24.*` от имени установившего пользователя. Webhooks в production не используются.
- **Без CDN на проде.** Все vendor-библиотеки (`xlsx.full.min.js`, `flatpickr.min.js`, `flatpickr.l10n.ru.js`) лежат локально в `vendor/` и попадают в ZIP.
- **Размер.** Жёсткий лимит платформы — 500 KB на ZIP.
- **Один HTML-файл — точка входа.** `index.html` подключает скрипты в правильном порядке: BX24.js → flatpickr (`defer`) → app.js (module, тоже отложен — выполняется после flatpickr). SheetJS (`vendor/xlsx.full.min.js`, ~950 KB) в `index.html` не подключён: `xlsx-export.ensureXlsx()` подгружает его при первом нажатии «Экспорт XLSX». В ZIP он есть.

## Обновление приложения

1. Внесите изменения в код, прогоните `npm test`.
2. `npm run pack` — пересоберите ZIP.
3. В интерфейсе локального приложения нажмите **Обновить** и загрузите новый ZIP. Конфигурация (код, права) сохранятся.
