# Debitorka — «Отчёт по счетам» для Битрикс24

Сводный отчёт по счетам (дебиторка) для портала `<portal>.bitrix24.ru`. Закрывает ограничение BI-конструктора Битрикс24, который не позволяет одновременно фильтровать по сроку оплаты и фактической дате оплаты.

- **Тип:** локальное приложение (тип 1, ZIP-архив, без бэкенда).
- **Стек:** Vanilla JS (ES2020) + vendored SheetJS, flatpickr.
- **Артефакт:** `dist/fin25_otch.zip` (≤ 500 KB).

## Вкладки и колонки отчёта

Две вкладки над таблицей с общими фильтрами (переключаются без перезагрузки, «Итого» на них совпадают):

- **Дебиторка по клиентам** — строка на контакт.
- **Дебиторка по сотрудникам** — строка на ответственного за счёт (первая колонка «Сотрудник», без ссылки; уволенные — с пометкой «(уволен)», счета без ответственного — «Без ответственного»).

1. **ФИО контакта** / **Сотрудник** — для контакта кликабельная ссылка, открывает карточку контакта в слайдере.
2. **Должен всего** — `SUM(opportunity)` по всем активным счетам контакта.
3. **Оплачено** — счета со стадией `DT31_5:P` («Оплачен»).
4. **Просрочено** — стадия ≠ `DT31_5:P` и `closedate < сегодня`.
5. **Остаток к оплате** — стадия ≠ `DT31_5:P`.

Фильтры: ответственный за счёт (multi-select; в списке только те, у кого есть счета за период), срок оплаты от/до (`closedate`), дата оплаты от/до (`ufCrmSmartInvoiceDatePay`). По умолчанию — текущий месяц.

Вверху панели фильтров — KPI **«% сбора дебиторки»** = Оплачено / Должен всего по текущему фильтру. XLSX выгружает активную вкладку (`debt_clients_YYYY-MM-DD.xlsx` / `debt_staff_YYYY-MM-DD.xlsx`).

с готовым заданием для ИИ-агента, — [docs/adapt-to-portal.md](docs/adapt-to-portal.md).

## Быстрый старт (разработчику)

Нужны только git и Node.js 20+. Python, Homebrew и глобальные npm-пакеты не нужны.

```bash
# 1. Тесты (без сети)
npm test

# 2. Вебхук портала (права crm и user) → .env и dev-config.local.js
npm run dev:setup -- https://<портал>.bitrix24.ru/rest/<ID>/<токен>/

# 3. Локальный сервер без кеша → http://localhost:8081/index.html
npm run serve

# 4. Сборка ZIP для загрузки в Битрикс24 (на Windows без zip — сначала npm install в папке проекта)
npm run pack          # → dist/<APP_CODE>.zip

# 5. После работ — удалить вебхук на портале (docs/adapt-to-portal.md, шаг 8)
```

## Безопасность

- `.env` и `dev-config.local.js` гитигнорятся и **не попадают** в ZIP-артефакт (см. `pack.mjs`).
- `B24_WEBHOOK_URL` используется только в dev-режиме (вне портала). На портале аутентификация — через `BX24.*`.
- Подробнее — в [docs/architecture.md](docs/architecture.md).
